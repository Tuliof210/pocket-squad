# Repository instructions

Before working in this repository, read these canonical files in order:

1. `.squad/PRODUCT.md`
2. `.squad/ARCHITECTURE.md`
3. `.squad/PROTOCOLS.md`

Read them once at the start of a run, not again on every message. `PRODUCT.md` defines what the
product is, `ARCHITECTURE.md` defines how it is built, and `PROTOCOLS.md` is authoritative for how
work is planned, implemented, verified, reviewed and delivered.

Before modifying tracked files, classify the change using `PROTOCOLS.md` and follow every applicable
protocol. If a mandatory protocol cannot be followed, stop and name the protocol and blocker; do not
silently bypass it.

Nested `AGENTS.md` and `AGENTS.override.md` files may add path-specific instructions and remain in force.
